📂 Проекты

Проект 01 — AI-администратор для барбершопа

Ниша: HoReCa / услуги

Telegram-бот, который отвечает клиентам 24/7: консультирует по услугам и ценам, записывает на стрижку через Google Calendar, отправляет напоминания за 2 часа до визита.

Стек: n8n · DeepSeek · Telegram Bot API · Google Calendar · Google Sheets

Результат: Время ответа клиенту: с 15–30 мин → 3–5 сек. Администратор экономит ~1.5 часа/день.


Проект 02 — AI-бот поддержки для интернет-магазина

Ниша: E-commerce (одежда)

3 связанных автоматизации:


Бот поддержки — отвечает на вопросы по заказам, принимает возвраты, FAQ, up-sell
Автоприём заказов — webhook → генерация заказа → запись в базу → уведомления
Мониторинг остатков — ежедневная проверка + Telegram-алерт менеджеру


Стек: n8n · DeepSeek · Telegram Bot API · Google Sheets

Результат: Время ответа: 10–30 мин → 3–5 сек (24/7). Экономия ~2 ч/день на поддержке.
